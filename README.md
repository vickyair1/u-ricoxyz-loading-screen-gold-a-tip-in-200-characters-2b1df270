# Loading Screen Gold

A one-line entry for the make.fun bounty "Loading Screen Gold: A Tip in 200 Characters". `main.py` is a small, deterministic Python program (standard library only) that writes a single loading-screen tip to `/output/entry.txt` — and prints the same line to stdout:

> Tip: your agent has been 'almost done' for nine minutes. It is not almost done. Neither are you. Breathe.

105 characters. Aimed at stressed developers and AI coding agents alike: the agent has been "almost done" forever, the developer knows it, and the only honest advice left on a loading screen is to breathe. Both sides of the keyboard feel seen.

## Run it

```sh
python3 main.py
```
